หน้า Simulation แบ่งง่าย ๆ เป็น 4 โซนหลัก: แถบบน, รายการอุปกรณ์, พื้นที่วางวงจร และแผงด้านขวา

![ภาพรวมหน้า Simulation](/img/simulation/screen-overview.png)

## 1. แถบบน

แถบบนใช้สำหรับสลับโหมดและควบคุมการจำลองหลัก เช่น `Compile`, `Run`, `Stop` รวมถึงเลือก board และ example

![แถบควบคุมด้านบน](/img/simulation/screen-controls-top.png)

## 2. รายการอุปกรณ์ทางซ้าย

ฝั่งซ้ายคือคลังอุปกรณ์ ใช้ค้นหาและเลือกชิ้นส่วนที่จะลากลงพื้นที่วางวงจร  
มีทั้งตัวกรองประเภทอุปกรณ์และช่องค้นหา

![รายการอุปกรณ์ทางซ้าย](/img/simulation/screen-components-panel.png)

## 3. พื้นที่วางวงจรตรงกลาง

ตรงกลางคือพื้นที่ทำงานหลัก ใช้วาง board, sensor, actuator และจัดตำแหน่งสายต่อให้ดูง่าย

- ใช้พื้นที่นี้ดูภาพรวมวงจร
- ลากอุปกรณ์จากฝั่งซ้ายมาวางได้
- จัดตำแหน่งก่อนทดลอง run

## 4. แผงด้านขวา

ฝั่งขวาใช้ทำงานกับโค้ดและผลลัพธ์

- `Code` สำหรับดูหรือแก้โค้ด
- `Mock Sensors` สำหรับปรับค่าจำลอง
- `Compiled`, `Serial Monitor`, `Serial Plotter` สำหรับดูผลลัพธ์

![แผงโค้ดและผลลัพธ์](/img/simulation/screen-code-output.png)

## ใช้งานให้คล่องแบบสั้น ๆ

1. เลือก example ด้านบน
2. ลากหรือเช็กอุปกรณ์จากฝั่งซ้าย
3. ดูวงจรตรงกลาง
4. Run แล้วดูผลที่แผงขวา
