# เริ่มต้นใช้งาน

หน้านี้พาเริ่มใช้หน้า Simulation แบบเร็วที่สุด

## 1. ดูโครงหน้าจอก่อน

หน้า Simulation แบ่งเป็น 3 ส่วนหลัก

- ซ้าย: รายการอุปกรณ์
- กลาง: พื้นที่วางวงจร
- ขวา: ปุ่มควบคุม, โค้ด, Mock Sensors และผลลัพธ์

![ภาพรวมหน้า Simulation](/img/simulation/getting-started-overview.png)

## 2. เลือกอุปกรณ์หรือเลือกตัวอย่าง

ถ้าจะเริ่มไว ให้เลือก example ที่มุมขวาบนก่อน แล้วค่อยดูโค้ดหรือวงจรตามตัวอย่างนั้น

![รายการอุปกรณ์ทางซ้าย](/img/simulation/getting-started-catalog.png)

## 3. Compile และ Run

ลำดับใช้งานหลักคือ

1. กด `Compile`
2. กด `Run`
3. ดูผลใน `Compiled`, `Serial Monitor` หรือ `Serial Plotter`

![แผงควบคุมและส่วนแสดงผล](/img/simulation/getting-started-code.png)

## 4. ทดลองค่าจำลองด้วย Mock Sensors

ถ้าตัวอย่างมีเซนเซอร์ ให้เปิดแท็บ `Mock Sensors` แล้วแก้ค่าที่ต้องการทดสอบได้ทันที

![แท็บ Mock Sensors](/img/simulation/getting-started-controls.png)

## เริ่มใช้งานแบบสั้น

1. เลือก board และ example
2. กด `Compile`
3. กด `Run`
4. ดูผลลัพธ์หรือปรับค่าใน `Mock Sensors`
