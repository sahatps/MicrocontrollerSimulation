HackCable Google Drive Share

For sender:
1. Open Docker Desktop and wait until it is running.
2. In this project folder, run:

   powershell -ExecutionPolicy Bypass -File .\EXPORT_HACKCABLE_TAR.ps1

3. Upload `hackcable.tar` to Google Drive.
4. Optionally upload this file too: `SHARE_ON_GDRIVE.txt`

For receiver:
1. Install Docker Desktop.
2. Download `hackcable.tar` from Google Drive.
3. Run:

   docker load -i hackcable.tar
   docker run -p 3000:3000 hackcable:latest

4. Open:

   http://localhost:3000

Notes:
- This package uses one public port: 3000
- This shared image includes native `clang` support for backend compilation
- Emscripten is not included in the shared image, to reduce size
- If port 3000 is busy, use:

   docker run -p 3001:3000 hackcable:latest

  Then open:

   http://localhost:3001
